# Security policy

Rhinoform is research software and is not a clinical or production medical
system. Do not use public issues to disclose credentials, private dataset
locations, licensed meshes, or participant-identifying material.

For a suspected security or privacy issue, contact the repository owner through
the private contact channel shown on their GitHub profile. Include the affected
commit, a minimal reproduction, and whether any licensed data may have been
exposed. Reproducibility defects that do not contain sensitive information may
be filed as ordinary GitHub issues.
